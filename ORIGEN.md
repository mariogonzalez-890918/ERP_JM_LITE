# ERP JM Lite

Producto comercial independiente creado el 29/10/2026 a partir de una base técnica previa.
Referencia de procedencia: commit 43e214d64b4d0f03a08dd3ba688b6622b61d0d5b.

Este repositorio contiene código, recursos genéricos y pruebas ficticias. No incorpora bases de otras empresas, credenciales de producción, clientes, maestros operativos, evidencias ni respaldos empresariales.

Los catálogos de clasificación SKU de instalaciones nuevas están vacíos y se configuran para cada empresa. Los datos operativos existentes conservan su trazabilidad. El sistema usa SQLite local y acceso web; la matriz Windows y la carga de 40–50 usuarios requieren validación antes de certificar la edición comercial.
